Como este cálculo ajuda

O que calcula

Compara uma média com um valor de referência, duas medidas pareadas ou duas médias independentes, estimando p-valor, intervalo de confiança e efeito.

Contribuição acadêmica

Ajuda a avaliar diferenças quantitativas entre condições, grupos ou momentos, com relato estatístico objetivo para artigo, TCC ou dissertação.

Exemplo simples

Um estudo compara a média de desempenho antes e depois de uma intervenção educacional para verificar se houve mudança relevante.

Método, uso e referência

Fórmula central
t = diferença / erro-padrão. Para grupos independentes, a calculadora usa Welch para graus de liberdade.
Quando usar
Use com variável quantitativa aproximadamente contínua. Com n pequeno, assimetria forte ou muitos outliers, considere uma alternativa não paramétrica ou análise robusta.
Referências
Student, 1908; Welch, 1947; Cohen, J. Statistical Power Analysis for the Behavioral Sciences.
